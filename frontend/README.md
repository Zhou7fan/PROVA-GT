# PROVA-GT Frontend

Nuxt 3 + Vue 3 frontend for the PROVA-GT system (UI name: *PatternWeave*).

## Quick start

```bash
npm install
npm run dev
```

Open http://localhost:3000. The five backend services must be running for full functionality — see the [root README](../README.md) for the complete setup instructions, API key configuration, and demo data.

## Production build

```bash
npm run build
node .output/server/index.mjs
```
